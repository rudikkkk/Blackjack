# Blackjack на C++

Игра «Блэкджек» на C++, написанная в рамках учебного проекта. Позволяет одному или нескольким игрокам сыграть партию против дилера с подсчётом очков, выбором действий и базовой проверкой корректного ввода.

## Правила игры

Цель — набрать сумму очков **не больше 21** и обыграть дилера:
- **Карты 2–10** приносят номинал.
- **Валет, Дама, Король** дают **10 очков**.
- **Туз** засчитывается как **11** или **1** очко (чтобы игрок не перебрал 21).
- **Блэкджек** — 21 очко с первых двух карт (Туз + карта достоинством 10).
- **Ход игрока:** можно взять ещё карту (*Hit*) или остановиться (*Stand*).
- **Ход дилера:** дилер добирает карты, пока его сумма меньше 17 очков.
