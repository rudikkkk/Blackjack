# Возможности на данный момент
* получить две карты
* увидеть их значение(2-10, J, Q, K, A) и масть(h - hearts, c - clubs, d - diamonds, s - spades)
* увидеть сумму карт на руках
* взять ещё карты (до 21 или до перебора)

# Компиляция 
из корня клонированного репозитория пишете 
```
g++ test.cpp
```
